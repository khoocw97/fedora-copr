# fedora-copr

个人 Fedora COPR 打包仓库。每个软件包对应本仓库根目录下的同名 `.spec`，源代码均来自下列上游项目。

## 字体

| 软件包 | 说明 | 上游来源 |
| --- | --- | --- |
| `lxgw-fonts` | 霞鹜文楷 Bright GB/TC + 霞鹜新晰黑 Plus | [LxgwBright](https://github.com/lxgw/LxgwBright)、[LxgwNeoXiHei](https://github.com/lxgw/LxgwNeoXiHei) |
| `maple-mono-fonts` | Maple Mono NF CN | [subframe7536/maple-font](https://github.com/subframe7536/maple-font) |

## 桌面与 Wayland

| 软件包 | 说明 | 上游来源 |
| --- | --- | --- |
| `fuzzel` | Wayland 应用启动器 / 模糊查找 | [dnkl/fuzzel](https://codeberg.org/dnkl/fuzzel) |
| `ly` | 轻量 TUI 显示管理器 | [fairyglade/ly](https://codeberg.org/fairyglade/ly) |
| `mangowm` | 基于 dwl 的 Wayland 合成器 | [mangowm/mango](https://github.com/mangowm/mango) |
| `scenefx` | wlroots scene API 替代实现（含特效） | [wlrfx/scenefx](https://github.com/wlrfx/scenefx) |
| `umbriel` | 基于 wlroots 的 Wayland 合成器 | [noctalia-dev/umbriel](https://github.com/noctalia-dev/umbriel) |
| `xdg-desktop-portal-umbriel` | Umbriel 的 xdg-desktop-portal 后端 | [noctalia-dev/xdg-desktop-portal-umbriel](https://github.com/noctalia-dev/xdg-desktop-portal-umbriel) |
| `xwayland-satellite` | 无根 Xwayland 集成 | [Supreeeme/xwayland-satellite](https://github.com/Supreeeme/xwayland-satellite) |
